Invite-only access control for WooCommerce with unique, single-use invite links and configurable access windows.

== Description ==

Invites & Access Control for WooCommerce lets a store operate as an invite-only shop while keeping the process simple for customers and administrators.

Features include:

* Turn invite-only purchasing on or off.
* Create unique, email-specific invite links.
* Set an access window from 1 to 365 days (7 days by default).
* Track issued, redeemed, expired, and purchased invites.
* Manage invites from a WooCommerce admin submenu.
* Customize the site name, sender identity, logo, and email branding.

When invite-only mode is disabled, normal WooCommerce purchasing behavior is restored.

== Installation ==

1. Install and activate WooCommerce.
2. Upload and activate this plugin.
3. Go to WooCommerce > Invites & Access Control.
4. Configure the invite system and create invites as needed.

== Usage ==

When invite-only mode is enabled, customers must use a valid invite link and remain within their access window to purchase.

Administrators can create, resend, redeem, expire, delete, and mark invites as purchased from the admin page.

== Important Notes ==

* WooCommerce is required.
* Invite links are intended to be used by the invited email address.
* Public invite links use their unique token as the authorization mechanism; WordPress admin nonces are not applicable to these logged-out customer links.
